# ProvisionMind Enterprise v0.8.2.1 RC

Initial public Release Candidate of ProvisionMind Enterprise.

## Highlights

- Unified infrastructure operations interface
- Proxmox VE integration
- VMware / vCenter visibility
- Hyper-V integration
- Proxmox Backup Server visibility
- Redfish physical hardware visibility
- Infrastructure inventory and resource relationships
- Provider health and validation
- Capacity visibility
- VM provisioning workflows
- Service plans
- Template/catalog management where supported
- Operations and workflow surfaces
- MFA and RBAC
- Session and security audit visibility
- AI-assisted infrastructure analysis / RCA surfaces

## Current Boundaries

This is a Release Candidate.

Some capabilities remain under active development. Hyper-V reference-VM/template catalog integration, deeper backup operations, broader telemetry, additional integrations and workflow automation remain areas for further development.

AI-assisted operations are intended to assist operators with infrastructure context and root-cause investigation. They are not presented as autonomous remediation.
