# ProvisionMind Enterprise

ProvisionMind is an infrastructure operations platform designed to bring multiple infrastructure environments into a unified operational interface.

## Supported Infrastructure

- Proxmox VE
- VMware / vCenter
- Microsoft Hyper-V
- Proxmox Backup Server
- Redfish-compatible physical hardware

## Current Public Release

**ProvisionMind Enterprise v0.8.2.1 RC**

The current Public Release Candidate is available at no cost.

The Windows installer is distributed through GitHub Releases.

## Security

ProvisionMind has been designed with security-focused operational controls including:

- Multi-Factor Authentication (MFA)
- Role-Based Access Control (RBAC)
- Session management
- Security audit visibility
- Controlled credential handling
- Provider validation
- Recovery mechanisms
- Explicit infrastructure authorization boundaries
